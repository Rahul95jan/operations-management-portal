# Operations Management Portal - Starter Kit

## Tech Stack
Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- FastAPI
- PostgreSQL
- SQLAlchemy

Infrastructure:
- Docker
- Redis
- Celery

## Modules Included
- Authentication
- Dashboard
- Session Scheduler
- Zoom Integration Placeholder
- Feedback Module
- Resource Upload Module
- Invoice Module

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
